🚀 一键自动抓取（推荐）

点击下方按钮会**自动打开浏览器**，你只需在弹出的窗口里登录小米账号并随便发一条消息， 程序会自动捕获凭证并保存，无需手动复制任何东西。

手动添加（备用）

如果自动抓取不可用，可手动操作：登录 aistudio.xiaomimimo.com， F12 → Network → 发送一条消息 → 找到 chat 请求 → 右键「Copy as cURL」→ 粘贴到下方。

⚠️ Chrome 130+ 默认会剥离 Cookie：请先在 DevTools → 设置(⚙️) → Preferences 中勾选 「Allow to generate HAR with sensitive data」。

模式行为
